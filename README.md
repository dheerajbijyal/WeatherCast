# 🌦️ WeatherCast — Weather Podcast Website

WeatherCast is a weather website that combines real-time weather information with spoken weather updates. It allows users to explore weather conditions and listen to weather reports through a simple, interactive interface.

## ✨ Features

* 🌍 Search weather by city.
* 🌡️ Display temperature and weather conditions.
* 💨 Show weather details such as humidity and wind speed.
* 🎙️ Generate spoken weather reports.
* 🔊 Listen to weather updates using text-to-speech.
* 📱 Responsive design for different screen sizes.
* 🎨 Modern and user-friendly interface.

*Note: Available features depend on the current implementation and API configuration.*

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Weather API
* Web Speech API

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/dheerajbijyal/WeatherCast.git
```

### 2. Open the project

Open the cloned folder in Visual Studio Code.

### 3. Run the website

If this is a static HTML, CSS, and JavaScript project, open `static/index.html` using the VS Code Live Server extension.

If your project also uses a Python backend, follow the backend setup instructions for that implementation.

## 🔑 API Configuration

If your project uses a weather API:

1. Create an account with your chosen weather data provider.
2. Generate an API key.
3. Configure the key according to your project's implementation.

**Security:** Never commit real API keys or other secrets to a public repository.
